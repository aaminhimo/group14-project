## Corrections needed after review

1. Mermaid's native `C4Context`/`C4Container` layout produced overlapping labels and crossing lines. The agent switched to flowcharts with C4 notation (type, technology, description, C4 colours).
2. Mermaid frontmatter must be the first line of the file; comments placed above it broke parsing. Fixed.
3. A `;` inside a sequence message is a statement separator in Mermaid. Replaced with `,`.
4. The analysis showed that persistence alone gives R² ≈ 0.46, so the design gained two model modes (what-if vs next-step, decision AD-06).
5. The first branch (`docs/v0.1.0-design-architecture`) was created in a fresh local repo, so it had no common history with `main` (which already contained PR #2), and GitHub cannot open a PR between unrelated histories. Fix: the commits were replayed onto `docs/v0.1.0-design`, branched from `main`. No force-push was used, the original branch is kept as evidence, and the two `.gitignore` files were merged.
